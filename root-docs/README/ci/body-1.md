## CI and the website

On every push and pull request GitHub Actions ([`.github/workflows/ci.yml`](.github/workflows/ci.yml))
checks formatting, types, tests and the README translations, then builds the models and the
site. From `main` the result is published to GitHub Pages: the home page is the site with the
3D model, and all STL files sit next to it for download.

>>>>> lang=ru
## CI и сайт

На каждый пуш и pull request GitHub Actions ([`.github/workflows/ci.yml`](.github/workflows/ci.yml))
проверяет форматирование, типы, тесты и переводы README, затем собирает модели и сайт.
Из ветки `main` результат публикуется на GitHub Pages: главная страница — сайт с 3D-моделью,
рядом лежат все STL для скачивания.

## CI והאתר

בכל דחיפה ובכל pull request ‏GitHub Actions ([`.github/workflows/ci.yml`](.github/workflows/ci.yml))
בודק עיצוב קוד, טיפוסים, בדיקות ותרגומי ה־README, ואז בונה את המודלים ואת האתר.
מהענף `main` התוצאה מתפרסמת ב־GitHub Pages: דף הבית הוא האתר עם מודל התלת־ממד,
ולצידו כל קובצי ה־STL להורדה.
